## class Variance {#class-variance}
- **Description**: Computes the sample variance for a numeric dataset
- **Constructor**:
  - `new Variance(values: number[])`
- **Methods**:
  - `value(): number` — returns the sample variance
- **Example**:
```ts
import { Variance } from 'your-lib'
const v = new Variance([1, 2, 3])
console.log(v.value())
```
